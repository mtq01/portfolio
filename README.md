# EMBURR — Mike's Portfolio

My original portfolio. Built with React, Vite, and JavaScript.

## Main Features
- Activity log that tracks every event taking place on the page. Just for fun (link clicks, mock errors, navigation)
- Admin/Guest access toggle. Some content is only available if you toggle into Admin mode.
